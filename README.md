# Neon Tetris

A complete client-side Tetris game website. It runs with no backend and requires no sign-in.

## Run locally

Open `index.html` in a modern browser.

## Deploy

Upload the three files (`index.html`, `styles.css`, `script.js`) to any static hosting service such as GitHub Pages, Cloudflare Pages, Netlify, or a standard web host.

## Features

- Classic 10×20 Tetris board
- 7-piece randomizer
- Ghost piece
- Next-piece preview
- Hold piece (C / HOLD)
- Keyboard and mobile touch controls
- Pause/resume
- Level progression and line clearing
- Local high score via localStorage
- Sound effects using Web Audio
- Light/dark theme toggle
- Responsive layout and reduced-motion support
